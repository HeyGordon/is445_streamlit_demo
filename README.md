# IS 445 HW6: Illinois Building Inventory

An interactive Streamlit application for IS 445 Homework 6. It explores how recorded floor area varies across county groups and how inventory records are distributed by construction decade.

- **Data:** [Course building inventory CSV](https://raw.githubusercontent.com/UIUC-iSchool-DataViz/is445_data/main/building_inventory.csv).
- **Interaction:** Agency selection and construction-year filtering update both charts.
