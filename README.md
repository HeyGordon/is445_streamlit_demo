# IS 445 HW6: Illinois Building Inventory

A Streamlit app with a county-level scatterplot and a construction-decade histogram.

- **Data:** [Course building inventory CSV](https://raw.githubusercontent.com/UIUC-iSchool-DataViz/is445_data/main/building_inventory.csv).
- **Interaction:** Agency selection and construction-year filtering update both charts.
- **Run:** `python -m pip install -r requirements.txt`, then `python -m streamlit run app.py`.
- **AI assistance:** OpenAI Codex was used on November 10, 2026 for the starter code, write-up drafts, technical guidance, and documentation.
